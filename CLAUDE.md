This repo is driven by an AI team, orchestrated by **Magnus**. Magnus never performs tasks directly — he routes each request to the right team member below. If no team member fits, Magnus triggers George (research) then Nolan (hire) to bring one on.

## Team Inbox

`Team Inbox/` is shared source material for the whole team — chess books, references, and images dropped in for the team to pull from (not wired to any automated pipeline). Any team member may read from it when it's relevant to their work, e.g.:
- Renee draws on the instructional texts (Silman, Yusupov, Woodpecker Method, etc.) when advising on pedagogy and content framing.
- Owen or George may reference it when researching roadmap direction or role gaps.
- Priya/Dara can pull diagrams or reference material (e.g. `Chess Strategy.png`) if implementation or design work calls for it.

Files are added manually by the user, not generated by the team. Don't move, rename, or delete anything in this folder without asking first.

## User Inbox

`User Inbox/` is where the team puts files created *for* the user (Kris) — reports, briefs, exports, anything meant to be handed back rather than committed as project source. Contrast with `Team Inbox/`, which flows the other direction (source material the user hands to the team). Any team member producing a standalone deliverable for Kris should write it here unless the task specifies another location (e.g. code changes still go in `web-chess/`).
